# Routina for macOS 1.3.1

Status: In development

Public version: 1.3.1

Build: 8

Snapshot reviewed: 2026-08-22

This is the macOS-facing change record currently planned since the 1.2.0 version boundary. Update it as scope changes, then mark it Released with the distribution date once the final build ships.

## Features and behavior changes

- Task Details can show a task's current custom-section path and let people edit that path through the normal task form.
- Custom Mac task sections now support nested subsections, any/all tag rules, direct move commands, and a pause/resume action for a whole super section.
- Backlog keeps empty super sections and subsections available for organization, lets both levels collapse, and has an in-workspace search for deferred tasks and their paths.
- The Planner Calendar List can be customized, allows eligible planned tasks to be marked Done in place, and supports custom completion durations and completion-time editing from Task Details.
- Planned task placement is additive: a task can remain in its normal section while also appearing in the appropriate day plan. Exact-date todos are planned automatically.
- Repeating routines use one progressive recurrence composer. It supports cadence-free routines, advanced fixed schedules, subdaily occurrences, availability windows, and preserved schedule details.
- Task Details and forms have a clearer progressive layout: optional priority and history are revealed only when wanted, tag suggestions stay compact, and full forms retain the task-list context.
- Linked tasks support clearer actions and a focused Link Task sheet. On supported Macs, relationship suggestions are started from that sheet and reviewed before any relationship is written.
- Task Flags can carry behavior rules, filter the task list, and explain why a search result is hidden by a flag. Eligible scheduled and rolling routines can use the Auto-assume done rule.
- User-completed task-list rows are grouped under an initially collapsed Completed disclosure. Calendar List exposes assumed-done rows in its own per-day disclosure.
- Support Diagnostics can copy a privacy-safe report and identifies the signed CloudKit environment of the running macOS executable.

## Bug fixes and reliability improvements

- Manual iCloud refresh now distinguishes an inactive request from a progressing first download, shows a linear activity bar and exact received-item count in Settings and Home, makes later refreshes incremental, and keeps local data available when recovery is needed.
- Fixed task paths, linked-task editing, selected timed outcomes, and assumed-done Planner updates so they resolve and refresh immediately.
- Fixed early completion and structured-recurrence projections in Today, duplicate recurrence summaries, and loss of advanced recurrence during CloudKit pulls.
- Fixed Mac form controls, task-detail time reveal and header layout, share-menu delay, the emoji-picker crash, and the full visual hit area of the task-link button.
- Fixed sidebar scroll flashes, Future-section jumps, context-menu lag, and repeat-control instability while improving Timeline, form, and search responsiveness with large histories.
- Fixed stale task-linker catalogs, assumed one-off Time-block confirmation, assumed-done filtering, and truncation of assigned Flag chips.
- Fixed the release helper's sandbox signing so the bundled macOS executable is valid for distribution.
