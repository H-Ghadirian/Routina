# Routina for macOS 1.4.0

Status: In development

Public version: 1.4.0

Build: 11

Snapshot reviewed: 2026-08-30

This is the current macOS release candidate. It supersedes the unreleased 1.3.1
draft and records the user-visible scope accumulated since the verified 1.2.0
version boundary. Mark it `Released` only after the Mac version ships.

## Features and behavior changes

- Planner, Backlog, Task Ladder, and Stats are integrated workspaces in the main
  window. One trailing workspace menu starts with Add New Task and Focus, then
  switches workspaces without opening separate windows.
- Planner, Backlog, and Task Ladder share the top search/create control while
  retaining independent queries and organizational context. Explicit Planner
  search can reveal matching Backlog tasks without moving them.
- Backlog supports persistent super sections and subsections, scoped automatic
  Tag rules, empty-section organization, search, direct task creation, and
  deliberate moves between Backlog and the main task list.
- Task Ladder ranks work independently by Pressure, Urgency, Importance,
  Thinking needed, or Estimated time; supports groups, inherited values,
  manually ordered metrics, search, and linked-child suggestions; and excludes
  paused, blocked, completed, archived, or deliberately hidden work.
- Repeating Due tasks can enter Task Ladder throughout, during an independent
  lead window, or only when due. Importance, Urgency, and Pressure can follow
  independent due-date progressions while the Base values remain editable.
- Workspace Filters live beside the workspace menu for Planner and Backlog.
  Planner combines Shared, Task List, Timeline, and Calendar scopes; Backlog
  offers its own bounded filters. Compact controls use aligned menu pickers while
  fullscreen editing keeps readable full-width choices.
- Shared Tags and Flags use searchable combined Include/Exclude popovers with
  visible active rules. The five built-in behavior Flags can hide work from Task
  Lists, Calendar List, Timeline, or Task Ladder, or automatically assume
  eligible work done.
- Stats uses compact single-choice filters, searchable Tags and Flags panels,
  and task-backed evidence lists opened from relevant metric rectangles.
- Planner remembers its Calendar/Timeline, Schedule/List, and preferred range
  choices; keeps narrow headers actionable; preserves manually owned placements;
  and lets Calendar List hide flagged tasks without losing their schedule or
  history evidence.
- Quick Add treats unqualified dates as availability, keeps reminder and preview
  choices interactive, accepts task destination addresses, and can derive an
  editable title from a pasted public URL.
- Task Details and forms keep Repeating and One-time configuration unified,
  group related Effort fields without conflating them, keep Focus separate from
  Actual time, adapt labels and actions to available width, and consolidate rich
  content without hiding populated sections.
- Main task-list rows reserve the first line for the title and can optionally
  show full multiline titles before secondary labels.
- Settings lists and controls the notification requests actually queued by the
  system. Settings search can match both destination titles and the controls
  inside them.
- AI Connections exposes privacy-safe product help through the bundled local MCP
  helper. Optional personal-task access is off by default, read-only, exported
  to a revocable local snapshot, and may be passed by the person's AI client to
  that client's provider.
- Backup export verifies a portable source receipt and attachments. Restore
  validates before one transactional replacement and retains the ten newest
  verified pre-restore recovery points while Routina remains installed.
- Task creation is unlimited. Support reports the exact version/build and uses
  Firebase Crashlytics for automatic production crash stacks without Google
  Analytics, a Crashlytics user ID, or task content.

## Bug fixes and reliability improvements

- Manual iCloud refresh reports received-item progress, distinguishes active
  transfers from stalls, advances incremental tokens only after successful
  merges, and preserves existing local data after failure.
- Fixed duplicate Planner blocks, schedule refresh after edits, Calendar List
  completion timing, assumed-done sections, day-header truncation, and card-field
  visibility at narrow widths.
- Fixed Task Ladder selection tint and singular selection across metrics,
  initialization and refresh of group editors, blocked-row refresh, bottom
  scrolling, and large-history responsiveness.
- Fixed Focus availability, tag-focus editing, remembered duration, duplicate
  Stats totals, and overnight activity so active intervals are attributed to the
  correct local days without paused gaps.
- Fixed Backlog refresh flicker, hierarchical task paths, cross-workspace search
  completeness, return-to-origin after creation, and embedded Task Detail
  presentation.
- Fixed Task Detail overflow and completion controls, effort popovers, linked
  task visibility, relationship wording, Flag visibility, stale history, and
  transition work when closing the companion pane.
- Reduced repeated full-history filtering, grouping, formatting, and summary
  work across Home, Planner, Timeline, Stats, forms, search, and sidebars.
- Hardened App Store archives by sandboxing the embedded MCP helper, including
  its matching dSYM, declaring exempt encryption, gating CloudKit schema drift,
  and correcting Firebase build-script inputs.
