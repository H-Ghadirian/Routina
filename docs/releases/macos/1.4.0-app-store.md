## Description

Routina is a flexible macOS planner for one-time tasks, repeating routines, focused work, and meaningful progress. It keeps daily planning practical while giving you detailed control when you need it.

PLAN YOUR DAY

• See today’s work, upcoming tasks, future plans, and overdue commitments in one organized app
• Arrange work across Day, 3 Days, or Week calendar views
• Review planned and completed activity in the Timeline
• Add planned dates, time blocks, estimates, deadlines, reminders, and availability windows
• Search or create tasks quickly from the main toolbar

ORGANIZE AND PRIORITIZE

• Keep someday and intentionally deferred work in a structured Backlog
• Create custom sections and subsections for the way you work
• Use Task Ladder to compare work by Importance, Urgency, Pressure, Thinking needed, or Estimated time
• Organize with searchable Tags and behavior Flags
• Hide selected work from task lists, Calendar List, Timeline, or Task Ladder without deleting it

BUILD ROUTINES THAT MATCH REAL LIFE

• Create one-time or repeating tasks
• Repeat after completion, follow a schedule, remain available without a schedule, or pause until needed again
• Set daily, weekly, monthly, yearly, and more advanced schedules
• Choose Due behavior for firm commitments or Gentle behavior for lower-pressure routines
• Use standard completion or flexible checklists

FOCUS WITH CONTEXT

• Start a Focus session for a task, a tag, or unassigned work
• Use count-up or fixed-duration sessions
• Pause and resume without counting break time
• Review focused time alongside task history and statistics

UNDERSTAND YOUR PROGRESS

• Explore detailed statistics for today, week, month, year, or a custom date range
• Review completions, active days, Focus time, repeating tasks, and open one-time tasks
• Filter statistics by task type, Tags, Flags, Importance, Urgency, and more
• Open supporting task evidence directly from relevant statistics

KEEP THE DETAILS THAT MATTER

Add descriptions, links, files, images, comments, history, Tags, Flags, and scheduling details to give every task the context it needs. Search quickly and keep important information close at hand.

Routina is designed for macOS with a spacious interface, Dark Mode, flexible sidebars, integrated Planner, Backlog, Task Ladder, and Stats workspaces, iCloud sync, and verified backup import and export.

Optional AI Connections provide product help through compatible AI clients. Personal-task access is read-only, off by default, and revocable.

## What's New in This Version

Routina 1.4.0 brings a more unified, capable, and responsive planning experience.

• Planner, Backlog, Task Ladder, and Stats are now integrated into the main window
• Organize deferred work with searchable Backlog sections and subsections
• Compare tasks in Task Ladder by Importance, Urgency, Pressure, Thinking needed, or Estimated time
• Search or create tasks from the toolbar, with improved date, reminder, tag, and link detection
• Use built-in Flags to hide selected work from task lists, Calendar List, Timeline, or Task Ladder
• Enjoy improved Planner filters, remembered views, more reliable placements, and clearer Calendar List review
• Open supporting task evidence directly from relevant Stats
• Work with clearer, more adaptable task forms and Task Details
• Export verified portable backups and restore with additional safeguards
• Connect compatible AI clients to product help and optional read-only task access

This release also fixes issues across Planner, Focus, Backlog, Task Ladder, Stats, Task Details, search, and iCloud refresh. It substantially reduces repeated processing for smoother scrolling and better performance with large task histories.
