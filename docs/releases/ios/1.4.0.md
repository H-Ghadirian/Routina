# Routina for iPhone 1.4.0

Status: In development

Public version: 1.4.0

Build: 13

Snapshot reviewed: 2026-08-30

This is the current iPhone release candidate. It supersedes the unreleased
1.3.1 draft and records the user-visible scope accumulated since the verified
1.2.0 version boundary. Mark it `Released` only after the iPhone version ships.

## Features and behavior changes

- Home, Search, New, Stats, and Settings are direct primary tabs. Home keeps
  Backlog, Timeline, and Task Ladder as its final workspace rows, while New
  consistently offers Create Task and Focus.
- A genuinely new installation focuses Home on creating the first task. After
  Routina observes any created, imported, restored, or synchronized task, the
  normal filters and workspace destinations remain available even if the task
  catalog becomes empty later. An empty Focus picker can open Create Task
  directly.
- iPhone now includes searchable Backlog and Task Ladder workspaces. Backlog
  preserves its section hierarchy and can return assigned work to Home. Task
  Ladder ranks work by Pressure, Urgency, Importance, Thinking needed, or
  Estimated time, supports nested groups and search, and explains excluded work.
- Repeating Due tasks can choose whether they enter Task Ladder throughout,
  during a configurable lead window, or only when due. Importance, Urgency, and
  Pressure can each follow an independent due-date progression while Thinking
  needed remains fixed.
- Tasks use the same Repeating and One-time configuration model throughout the
  app. Repeating work supports cadence-free `When needed`, after-completion, and
  calendar schedules without exposing discarded pre-release task kinds.
- Task Details and forms keep Importance, Urgency, Pressure, and Thinking needed
  independent; group Estimate, Actual time, Story points, and Focus under one
  Effort concept; and keep Focus history separate from manually recorded Actual
  time. Calendar expansion is remembered per task.
- Tasks can store a destination address independently of experimental saved
  Places. A resolved destination appears with a map and Apple Maps or Google
  Maps actions.
- The five built-in Flags can hide work from Task Lists, Calendar List,
  Timeline, or Task Ladder, or automatically assume eligible work done. Task
  creation is unlimited and no purchase entitlement or task-count paywall is
  shown.
- Filters use persistent grouped choice sheets with explicit All, None, exact,
  and threshold meanings. Tag selection stays searchable, and every active tag
  rule remains visible in the filter summary.
- Settings lists the notification requests actually queued on the device,
  groups them by task or event, and can remove or defer one occurrence without
  changing the source task or its sibling alerts.
- Backup export verifies a portable source receipt and attachment hashes.
  Restore validates before one transactional replacement and retains the ten
  newest verified pre-restore recovery points while Routina remains installed.
- Support reports the exact version and build, offers privacy-safe diagnostics,
  and uses Firebase Crashlytics for automatic production crash reports without
  Google Analytics, a Crashlytics user ID, or task content.
- Production omits Apple Health, Places location services, Screen Time blocking,
  Beta Experiments, iPad support, and the Apple Watch companion. The iPhone app
  continues to include the production widget.

## Bug fixes and reliability improvements

- Manual iCloud refresh now distinguishes active progress from a stall, reports
  the received-item count, saves incremental change tokens only after a
  successful merge, and leaves existing local data available after failure.
- Search, Home, Timeline, Stats, task forms, Task Details, and large-history
  filters avoid repeated whole-history work while scrolling. Inactive retained
  tabs defer synchronization-driven presentation rebuilding until visible.
- Fixed stale or duplicated Focus history, cross-device active Focus state, and
  overnight Focus attribution so active intervals are split across the correct
  local calendar days without counting paused gaps.
- Fixed Task Ladder selection, navigation history, linked-task blocking, and
  due-window refreshes after task changes.
- Fixed collapsed Task Detail toolbar actions, title persistence, Goal
  visibility gating, empty Linked Tasks presentation, and completion-action hit
  areas and semantic colors.
- Fixed recurrence summaries, Quick Add availability detection, synced schedule
  preservation, notification suppression for automatically assumed work, and
  early completion of eligible untimed scheduled routines.
- Stats no longer shows Cards/Compact, Edit, or Filter controls when the
  corresponding content or action is unavailable, and empty Tag settings no
  longer show a Tag Counters control without a tag to count.

## Known issues

- No iPhone-specific known issue has been entered for this release candidate.
