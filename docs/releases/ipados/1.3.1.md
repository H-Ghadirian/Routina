# Routina for iPad 1.3.1

Status: In development

Public version: 1.3.1

Build: 8

Snapshot reviewed: 2026-08-09

This is the iPad-facing change record currently planned since the 1.2.0 version boundary. It is separate from the iPhone record even though the current app uses the same universal iOS target.

## Features and behavior changes

- Tasks support Markdown descriptions and a Thinking needed complexity value.
- Guided reviews help fill in missing importance, urgency, pressure, and thinking-needed information. Help Me Choose uses bounded comparisons to suggest a task without unbounded work.
- Task Flags can carry behavior rules, filter the task list, and explain why a task is hidden by a flag. Eligible scheduled and rolling routines can use the Auto-assume done rule.
- Repeating routines use one progressive recurrence composer. It supports cadence-free routines, advanced fixed schedules, subdaily occurrences, and availability windows.
- Task Details have adaptive metadata and place Add more details after the visible task content. Apple Intelligence relationship suggestions are intentionally macOS-only; iPad keeps the manual linking flow.
- The New action opens its single available destination directly. Task type labels, pressure filters, Stats metric tiles, and Focus 2048 details have been refined for compact and regular iPad layouts.
- Support Diagnostics can copy one privacy-safe report. It explicitly states when iPadOS cannot inspect the installed binary's signed CloudKit environment.
- Production builds leave unreleased location services and Screen Time blocking out entirely while development builds can retain their work in progress implementations.
- The first production phase does not include the Apple Watch companion or start its connectivity relay; the companion implementation remains available for a later release.
- The first production phase does not include Apple Health movement stats or request HealthKit access.

## Bug fixes and reliability improvements

- Manual iCloud refresh now distinguishes an inactive request from a progressing first download, shows a linear activity bar and exact received-item count in Settings and Home, makes later refreshes incremental, and keeps local data available when recovery is needed.
- Fixed Markdown blocks so paragraphs, lists, and other structure render as intended.
- Fixed Timeline refresh after synced activity, stale Focus sessions after cross-device sync, and Timeline appearance previews.
- Fixed the New action's feature gates, pressure-filter layout, single-task row numbering, and filter preservation after returning from Stats.
- Improved main-screen, Stats, task-detail, recurrence-form, and guided-review performance; their large-history work is cached instead of repeating during scrolling.

## Known issues

- No iPad-specific known issue has been entered for this snapshot.
