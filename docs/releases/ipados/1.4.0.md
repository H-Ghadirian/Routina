# Routina for iPad 1.4.0

Status: Deferred before release

Public version: 1.4.0

Build: 13

Scope changed: 2026-08-31

This prepared iPad candidate was removed from the first production scope before
release because the iPad experience is not ready and has multiple unresolved
issues. Routina's iOS targets now build for iPhone only. The adaptive source is
retained for future work, but the material below is a development snapshot, not
a claim of supported or release-ready iPad behavior.

## Retained development snapshot

- Home, Search, New, Stats, and Settings are direct primary destinations in the
  regular iPad layout. Home keeps Backlog, Timeline, and Task Ladder as its final
  workspace rows, while New consistently offers Create Task and Focus.
- A genuinely new installation focuses Home on creating the first task. After
  Routina observes any created, imported, restored, or synchronized task, the
  normal filters and workspace destinations remain available even if the task
  catalog becomes empty later. An empty Focus picker can open Create Task.
- iPad now includes searchable Backlog and Task Ladder workspaces. Backlog
  preserves its section hierarchy and can return assigned work to Home. Task
  Ladder supports its five metrics, nested groups, search, ordering, task
  details, and clear explanations for excluded work.
- Repeating Due tasks can choose whether they enter Task Ladder throughout,
  during a configurable lead window, or only when due. Importance, Urgency, and
  Pressure can each follow an independent due-date progression.
- Tasks use one Repeating and One-time configuration model. Repeating work
  supports cadence-free `When needed`, after-completion, and calendar schedules
  without exposing discarded pre-release task kinds.
- Task Details and forms keep the four Task Ladder values independent, group
  Estimate, Actual time, Story points, and Focus under Effort, keep Focus history
  separate from Actual time, and remember Calendar expansion per task.
- Tasks can store an address independently of experimental saved Places. A
  resolved destination appears with a map and Apple Maps or Google Maps actions.
- Five built-in Flags control Task List, Calendar List, Timeline, Task Ladder,
  and Auto Assume Done behavior. Task creation is unlimited and has no
  task-count paywall.
- Filter choices use readable grouped rows across compact and regular widths,
  active Tag rules remain visible, and tag selection is searchable.
- Settings groups the notification requests actually queued by the system and
  can remove or postpone one occurrence without altering its source task or
  sibling alerts.
- Verified backup receipts, attachment hashes, transactional restore, and ten
  retained pre-restore recovery points protect transfers and later recovery.
- Support identifies the exact version and build, provides privacy-safe
  diagnostics, and uses Firebase Crashlytics for production crash reports
  without Google Analytics, a Crashlytics user ID, or task content.
- The retained development implementation omits Apple Health, Places location
  services, Screen Time blocking, Beta Experiments, and the Apple Watch
  companion. This is not a current iPad release claim.

## Bug fixes and reliability improvements

- Manual iCloud refresh reports real transfer progress, advances incremental
  tokens only after a successful merge, distinguishes inactivity from a long
  active transfer, and preserves existing local data after failure.
- Search, Home, Timeline, Stats, task forms, Task Details, and large-history
  filters avoid repeated whole-history work while scrolling and defer inactive
  tab refresh work until needed.
- Fixed duplicated or stale Focus history, cross-device active timer state, and
  overnight Focus attribution across local calendar days.
- Fixed Task Ladder selection and navigation history, linked-task blocking,
  recurrence preservation, collapsed Task Detail actions, Goal visibility, and
  empty Linked Tasks presentation.
- Fixed automatically assumed notification behavior, scheduled-routine early
  completion, task-detail title persistence, and full-surface interaction for
  custom controls.
- Stats omits toolbar controls that have no available content or action, and
  empty Tag settings omit Tag Counters until at least one Tag exists.

## Known issues and release status

- The iPad experience has multiple unresolved functional and layout issues and
  has not passed release verification. Individual issues must be reproduced,
  fixed, and covered before a future iPad candidate is proposed.
- Restoring support requires an explicit scope decision plus complete iPad
  functional, layout, performance, archive, and launch verification.
