# UC-NNN — Outcome-Oriented Name

**Status:** Working assumption | User-validated | Revised from feedback

**Availability:** Production | Development experiment | Proposed | Mixed

## Situation

Describe what is happening in the person's life when this need appears. Do not begin with a screen or feature.

## Need

Write the need in the person's language: “I need to … so that …”

## Desired Experience

Describe the smallest coherent journey from entry to outcome. Include important decisions, feedback, and recovery paths without implementation details.

## Successful Outcome

State what the person can understand, accomplish, or trust at the end.

## Example

Use realistic content, dates, timing, or constraints that make the case concrete.

## Variations and Edge Cases

- Platform differences that materially affect the journey.
- Empty, unavailable, interrupted, offline, error, or permission-denied states.
- Accessibility, privacy, and recovery expectations.

## Evidence

Link user feedback, research, support themes, or state that the case remains a working assumption.
